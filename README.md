# Simple Application Form

A clean, responsive, and easy-to-use application form built with standard HTML and CSS. This project provides a basic UI template for user registration or application purposes.

## Features

  **User Inputs:** Includes fields for First Name, Last Name, Email, Password, and Confirm Password.
  **Form Validation:** Utilizes basic HTML5 validation to ensure required fields are filled out before submission.
  **Modern Styling:** Features a centered, responsive card layout with custom CSS styling and a hover effect on the submit button.

## Technologies Used

  HTML5
  CSS3

## How to Use (Local Setup)

Follow these steps to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You will need to have Git installed on your computer to clone the repository. If you don't have it, you can download it from [git-scm.com](https://git-scm.com/).

### Installation Steps

1.  **Clone the repository:**
    Open your terminal or Git Bash and run the following command to clone the project to your local machine:
    
   bash
    git clone [https://github.com/manoj-0909/F9-EXP1.git](https://github.com/manoj-0909/F9-EXP1.git)
   

2.  **Navigate to the project folder:**
    Move into the directory that was just created:
    
   bash
    cd F9-EXP1
   
3.  **Run the application:**
    Because this is a static webpage, no server installation is required. Simply locate the HTML file (exp1.html) in your file explorer and double-click it to open it in your default web browser.
